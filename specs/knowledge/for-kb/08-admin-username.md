# 接受邀请须填用户名（用户名 ≠ 姓名）

管理员邀请落地页必须同时收集：

| 字段 | UI 文案 | 用途 |
| --- | --- | --- |
| `username` | **用户名**（勿写「登录名」） | 登录、管理员列表第一列 |
| `display_name` | **姓名**（英文） | 顶栏 Hello |
| 密码 | 新密码 / 确认 | 设密后 `must_change_password=false` |

## 规则

- 用户名：字母开头；字母、数字与 `._-`；长度 3–64；库内唯一（大小写不敏感）。
- 姓名：既有英文姓名规则。
- 登录仍可用 **用户名或邮箱** + 密码。
- 软禁用后再邀请激活时，同样写入用户名。

## 常见故障

旧流程只填姓名会导致 `username` 为空，列表显示 `—`。处理：软禁用后重新邀请，或手工回填用户名；不要默认用邮箱 @ 前本地部分当用户名。
