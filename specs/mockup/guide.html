Connect

接入指南

用同一把 API Key 连接 Cursor、ChatBox 或自有应用。调用方自带大模型；本服务提供知识工具。

1. 获取 API Key

  1. 请管理员在管理台签发一把使用者 Key（明文仅显示一次）。
  2. 妥善保存；吊销后立即失效，重签会更换密钥但知识库保留。

2. 鉴权

所有知识面请求使用：

Authorization: Bearer <api_key>

3. MCP（Cursor / ChatBox）

  • 配置远程 MCP，指向本站公开的 MCP 端点（上线后见部署说明）。
  • 工具含检索、列表、提案、确认、批量导入等；不提供业务策略工具。
  • 写入必须确认后才会索引。

4. REST（如 HCP）

  • 与 MCP 工具语义对齐，路径形如 /api/v1/kb/*。
  • 同样使用 Bearer Key；请求体中的用户标识不能覆盖 Key 身份。

5. 边界

  • 可帮你找到并管好知识；不替你做投放策略或业务决策。
  • 外部材料须提案并确认后入库；禁止无确认自动进库。
